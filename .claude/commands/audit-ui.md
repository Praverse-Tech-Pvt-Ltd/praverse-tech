# /audit-ui

Audit the Praverse website UI.

Use:
- praverse-brand
- responsive-qa
- animation-performance
- content-strategy

Check:
1. Brand consistency
2. Premium futuristic feel
3. Mobile responsiveness
4. Text readability
5. CTA clarity
6. Animation smoothness
7. Layout overflow
8. Duplicate/spaced text issue
9. Section hierarchy
10. Performance risks
11. Accessibility
12. Contact visibility

Output:
- Critical issues
- Major issues
- Minor issues
- Recommended fixes
- Files requiring changes
