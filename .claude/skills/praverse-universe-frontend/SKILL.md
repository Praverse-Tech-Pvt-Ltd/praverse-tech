# Praverse Universe Frontend Skill

## Purpose
Use this skill to implement the Praverse Tech futuristic website frontend.

## Recommended Stack
Use:
- Next.js
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React icons

Use Three.js / React Three Fiber only if absolutely required and only inside isolated lazy-loaded components.

## Design Language
Use a premium dark futuristic design:
- Deep space background
- Star particles
- Glassmorphism cards
- Cyan and violet accent glow
- Holographic gradients
- Soft motion
- Smooth scroll storytelling
- Clean typography
- Strong mobile responsiveness

## Core Components to Build
- HeroUniverse
- StarfieldBackground
- NovaRobotGuide
- SpaceTour
- InnovationStationCard
- FutureTechEcosystem
- HealthMateShowcase
- PharmaAIRegulatorySection
- FederatedLearningSection
- BiochipPhotonicsLab
- GPUCloudInfrastructureSection
- RoboticsAutonomousSystemsSection
- ResearchTimeline
- VentureLabSection
- PartnerCTA
- Footer

## UI Behavior
- Smooth scroll
- Subtle parallax
- Section reveal animations
- Hover glow on innovation cards
- Robot guide message changes based on active section
- Mobile vertical journey layout
- Reduced-motion fallback

## Performance Rules
- Keep first load lightweight
- Avoid heavy 3D in initial version
- Use CSS and Framer Motion before Three.js
- Lazy-load visual-heavy sections
- Optimize images and SVGs
- Avoid layout shift
- Respect prefers-reduced-motion
- Keep Lighthouse performance target above 85
