# Responsive QA Skill

## Purpose
Use this skill before finalizing Praverse website work.

## Required Viewports
Check:
- 390px mobile
- 430px mobile
- 768px tablet
- 1024px laptop
- 1440px desktop
- 1920px wide desktop

## Verify
- No horizontal scroll
- Hero text does not overflow
- Nova robot guide does not cover content
- Space tour works on mobile
- Cards stack correctly
- Navigation is usable
- Buttons are visible
- Footer is readable
- Text contrast is strong
- Animations are smooth
- Reduced motion works

## Output
Provide:
- Issues found
- Files changed
- Screens tested
- Remaining risks
