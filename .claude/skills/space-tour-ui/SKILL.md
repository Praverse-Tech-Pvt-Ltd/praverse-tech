# Space Tour UI Skill

## Purpose
Use this skill to create the Praverse Space Tour section.

## Concept
The user travels through the Praverse Universe. Each domain is represented as a futuristic space station, planet, orbital node, or holographic research lab.

## Required Innovation Stations
1. AI Core Station
2. HealthMate Humanoid Station
3. Pharma AI and FDA 483 Station
4. Federated Learning Station
5. Vision AI Station
6. Healthcare Kiosk Station
7. Robotics and Autonomous Systems Station
8. Biochip Intelligence Station
9. Photonics Station
10. GPU and AI Cloud Infrastructure Station
11. Edge AI / AIoT Station
12. Research and Publications Station

## Desktop Layout
- Orbital or cosmic map style
- Central Praverse core
- Innovation stations around it
- Nova guide on one side
- Holographic station cards

## Mobile Layout
- Vertical journey timeline
- Station cards stacked cleanly
- Nova message between major sections
- No horizontal overflow

## Interactions
- Hover: station glows
- Click: station expands with details
- Start Tour button scrolls to first station
- Active station changes Nova message

## Tone
Short, cinematic, premium, credible.

Example:
"Entering Pharma AI Station — where regulatory intelligence, FDA 483 analytics, and GMP workflows become decision-ready systems."
