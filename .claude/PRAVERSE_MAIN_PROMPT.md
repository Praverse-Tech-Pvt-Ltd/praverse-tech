# Main Claude Prompt for Praverse Website Redesign

We need to redesign praversetech.com into a premium futuristic AI universe website.

Current expanded Praverse positioning:
Praverse Tech is a future technology company building human-centered intelligent systems across AI, ML, healthcare AI, HealthMate, humanoid robotics, pharma AI, FDA 483 regulatory intelligence, GMP automation, federated learning, computer vision, biochips, photonics, GPU/cloud AI infrastructure, healthcare kiosks, warehouse robotics, autonomous systems, edge AI, AIoT, research publications, and product incubation.

The website must not look like a normal AI startup website. It should feel like a user is entering the "Praverse Universe."

Core experience:
When a visitor opens the website, they should feel like they are travelling through a futuristic space universe. A humanized virtual robot guide named Nova should welcome the visitor and guide them through different Praverse innovation stations.

Main concept:
"Enter the Praverse Universe."

Hero section:
- Deep space background
- Animated starfield
- Premium glowing Praverse identity
- Nova robot guide
- Heading: "Enter the Praverse Universe"
- Subheading: "Engineering human-centered intelligence across AI, robotics, healthcare, pharma automation, biochips, photonics, and AI infrastructure."
- CTA buttons:
  - Start Space Tour
  - Explore the Ecosystem
  - Meet HealthMate
  - Partner With Praverse

Create a guided journey through:
1. AI Core Station

6. Healthcare Kiosk Station
7. Robotics and Autonomous Systems Station

- Work beautifully on mobile

Design requirements:
- Premium dark futuristic design
- Deep space / cosmic feel
- Glassmorphism
- Holographic cards
- Cyan, blue, violet glow
- Smooth animations
- Clean typography
- Professional, not childish
- Investor/client/researcher friendly
- Mobile responsive
- Performance optimized

Technical requirements:
- Use existing project stack where possible.
- Prefer Next.js, React, TypeScript, Tailwind CSS, Framer Motion if available.
- Avoid heavy 3D in first version unless already present and optimized.
- Use lightweight starfield/particles.
- Lazy-load heavy visual sections.
- Respect prefers-reduced-motion.
- Fix duplicated/spaced text rendering issue if present.
- Run lint/build and fix all errors.
